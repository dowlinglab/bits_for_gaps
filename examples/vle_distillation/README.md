# VLE / distillation case study (Phase 6)

The paper's H2O–PrOH vapor–liquid-equilibrium case study. To be ported here onto the
public `bits_for_gaps` API in Phase 6: activity model (Wilson via Julia/Clapeyron),
Gibbs–Duhem, phase diagram, McCabe–Thiele distillation. Requires `pip install -e ".[vle]"`
and (macOS) `PYTHON_JULIACALL_HANDLE_SIGNALS=yes`.
